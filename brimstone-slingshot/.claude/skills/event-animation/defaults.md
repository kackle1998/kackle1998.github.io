# Event animation defaults

The "standard" answers: the starting picks for a new event, and the reuse question (SKILL.md,
step 0). The builder's panel starts from the place picks; the reuse standard is offered first,
marked (Recommended). When the user picks something else and says to keep it as
the standard, update this file.

| Question | Standard |
| --- | --- |
| Setting | ruins |
| Background | the setting's own scatter to the horizon, with a wall of tall props hiding the far edge |
| Props | three near props framing the action (two tall, one low), plus the setting's heat prop |
| Background life | the setting's own life (ruins: ash, or embers at ante 2 and 3) |
| Reuse | the figurine landing on the tail of the lob (`Scene.land`), and the slingshot if it's used |
| Camera | Bone Draft's framing: `Scene.mount(stage, { rows: 700, top: 90 })` |
| Designs | three (A, B, C), one per idea, checked at each ante with the template's Ante buttons |
