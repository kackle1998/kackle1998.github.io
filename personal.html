Brimstone Slingshot

JavaScript Game Design Pixel Art Supabase

Brimstone Slingshot is a pet project of mine. The goal is to mix and match the rules of the trading card games Magic the Gathering and Yu-Gi-Oh, as well as other favorites of mine in a retro pixel-art aesthetic. The game is built in JavaScript and playable in any web browser on desktop and mobile.

Click the screenshot to play!

  • The game features both online play against opponents (programmed using Supabase) as well as an offline "story mode." The story is still a work in progress. I'm aiming for a hybrid celestial / spellslinger theme to pair with the game's art style.
  • The art for the majority of the game's creatures, spells, and other cards were made within the game itself under the onboard pixel art engine. Any user is allowed to create an account with a password (just a 4-digit pin) and create their own cards and decks.
  • This is a live project, which is at times a bit volatile depending on my mood for the day. Sometimes I'll want to add crazy new features (there's a secret boss battle coming up!), or just minor tweaks to the graphics engine. Realistically, the project is just updated when creativity strikes.
